# Jujutsu Project

Bot de Discord feito com discord.js.

## Como usar
1. Instale o Node.js 18+.
2. `npm install`
3. Copie `.env.example` para `.env` e coloque o token do bot.
4. `npm run deploy` (registra os slash commands)
5. `npm start`

## Comandos
- `/ping` - mostra a latência do bot

## Estrutura
- `src/commands/<categoria>/` - comandos
- `src/events/` - eventos do Discord
